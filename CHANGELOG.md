# Changelog

## 1.1.0 — 2026-11-07

- First public release of the native background service.
- Detect the predominant Chinese script in selected text before converting.
- Replace the Automator startup path with a resident AppKit service.
- Provide a universal macOS application, per-user installer and uninstaller.
- Register Hyper+C and restore prior shortcut settings on uninstall where unchanged.
